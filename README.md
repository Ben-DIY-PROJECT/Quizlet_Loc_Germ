# Quizlet_Loc_Germ

Quizlet_Loc_Germ is a self-designed vocabulary learning application inspired by Quizlet, focused on helping users study German–English word pairs locally.

The project emphasizes clean MVC architecture, local data storage, and an intuitive UI for reviewing and testing vocabulary without relying on online services.

---

## Features

- Local German–English word pair management  
- Multiple study modes (e.g. reading / review / quiz-style interaction)
- MVC-based design for clear separation of model, view, and controller
- Java-based implementation suitable for coursework and personal projects

---

## Tech Stack

- Java  
- JavaFX  
- MVC design pattern  
- Git & GitHub for version control
- SQLite
